# Third-party credits

**DLSS, Reflex and Streamline** are developed by NVIDIA. The mod uses the Streamline headers and ships their notices. Players who want DLSS or Reflex obtain the production runtime and its terms directly from NVIDIA. The tested NGX DLLs have file version 310.9.16.0. [Streamline 2.14.16](https://github.com/NVIDIA-RTX/Streamline/releases/tag/v2.14.16)

**AMD FidelityFX™.** The signed DX12 loader and frame-generation DLL come from FSR SDK 2.4.0. The mod uses the FSR 3.1.6 interpolation provider and 3.1.7 swap chain. The package includes AMD's distribution terms and third-party notices. [AMD SDK release](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK/releases/tag/v2.4.0)

**MinHook.** The native bridge links the x64 static library by Tsuda Kageyu. Its BSD notices and those for the included HDE code accompany the binary. [MinHook 1.3.4](https://github.com/TsudaKageyu/minhook/releases/tag/v1.3.4)
